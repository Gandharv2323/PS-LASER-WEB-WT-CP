# CS3111 Web Technologies — unit topics to cover (from the course syllabus the owner shared)

Every topic below must be demonstrated somewhere in the PS Laser project and mapped in `docs/syllabus/unit-*.md`.

## Unit I — Server-Side Technologies (PHP)
Introduction to PHP, features, sample code, PHP script working, PHP syntax, conditions & loops, functions, string manipulation, arrays & array functions, form handling, cookies & sessions, file handling, exception handling, e-mail validation, MySQL with PHP, Laravel (the PHP framework).

## Unit II — React
Introduction to React, React component, JSX, render function, Component API, component lifecycle, state, props, component composition, pass data parent → child, pass data child → parent, component styling, forms, events, refs, keys, Router, Flux, Redux.

## Unit III — Server-Side Technologies (Java)
Servlet: servlet architecture overview, a "Hello World" servlet, servlets generating dynamic content, servlet life cycle, parameter data, sessions, cookies, URL rewriting, other servlet capabilities, data storage, servlet concurrency, databases (MySQL) and Java servlets.
JSP: introduction to Java Server Pages, JSP and servlets, running JSP applications, basic JSP, JavaBeans classes and JSP, support for the Model-View-Controller paradigm, JSP-related technologies (JSTL/EL, custom tags, filters/listeners).

## Unit IV — Spring Boot
Spring Framework, Spring Boot framework, installing Spring Boot, build tool (Maven/Gradle/Ant), core features, Spring Security, web applications, JPA for database connectivity, working with SQL and NoSQL, messaging, testing, deploying Spring Boot applications, monitoring and testing, Postman for API testing.

## Unit V — Advanced React
TypeScript integration, complex performance tuning, server-side rendering, robust state libraries, core advanced concepts & hooks, state management and API integration, advanced component patterns and architecture.

## Unit VI — Node JS
Introduction to Node JS, installation of Node JS, Node JS modules, Node Package Manager (NPM), creating a web server, file system, Express JS, serving static resources, database connectivity.
