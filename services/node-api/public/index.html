Enquiry API

Node.js 24 + Express · port 4000 · CS3111 Unit VI

checking…

Stores website enquiries (with an optional CAD drawing) in the shared pslaser MySQL database and returns a WhatsApp link so every quote stays WhatsApp-first. Staff routes accept the JWT issued by the Spring Boot API (POST :8081/api/auth/login).

GET /api/health

Process liveness + MySQL ping + os facts. Shape: { ok: true, db: true|false, ... }

curl http://localhost:4000/api/health

POST /api/enquiries

Public, rate-limited. JSON or multipart/form-data. Fields: name, phone, message (required), email, serviceSlug, machineSlug, source (next | react | php | laravel | jsp | spring | node; default node). Optional file drawing: dxf, dwg, pdf, png, jpg ≤ 10 MB. Returns 201 { id, whatsappUrl }.

curl -X POST http://localhost:4000/api/enquiries \
  -H "Content-Type: application/json" \
  -d '{"name":"Asha Patil","phone":"9876543210","serviceSlug":"laser-cutting","message":"50 pcs MS 3 mm brackets"}'
curl -X POST http://localhost:4000/api/enquiries \
  -F name="Asha Patil" -F phone=9876543210 -F message="Please quote this part" \
  -F drawing=@bracket.dxf

GET /api/enquiries admin / staff

Paginated list, newest first. Query: page, pageSize (≤ 100), status (new | contacted | quoted | won | lost). Returns { items, page, pageSize, total, totalPages }.

curl "http://localhost:4000/api/enquiries?status=new&page=1" -H "Authorization: Bearer $TOKEN"

PATCH /api/enquiries/:id admin / staff

Body { "status": "contacted" }. Returns the updated enquiry.

curl -X PATCH http://localhost:4000/api/enquiries/12 -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"status":"contacted"}'

GET /api/enquiries/:id/drawing admin / staff

Streams the private drawing upload (uploads are never served as static files).

curl -OJ http://localhost:4000/api/enquiries/12/drawing -H "Authorization: Bearer $TOKEN"

GET /api/catalogue

Machines + services from MySQL, cached in memory for 60 s (X-Cache: HIT|MISS).

curl http://localhost:4000/api/catalogue

GET /api/logs/requests admin

Tail of the request log streamed from disk (?bytes=8192), or ?download=1 for the whole file.

curl "http://localhost:4000/api/logs/requests?bytes=2048" -H "Authorization: Bearer $TOKEN"

Errors

Same shape as the Spring API: { status, error, message, fieldErrors?, requestId }. 401 = missing/invalid token, 403 = wrong role, 413 = file too large, 429 = rate limited.
